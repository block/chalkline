# Governance

This project follows Block Open Source governance: see [block/.github/GOVERNANCE.md](https://github.com/block/.github/blob/main/GOVERNANCE.md).

Project-specific detail: normative changes to `setup/PROTOCOL.md` or the frontmatter contract in `AGENTS.md` require review by one content/design maintainer **and** one technical maintainer (see [CONTRIBUTING.md](CONTRIBUTING.md)).
