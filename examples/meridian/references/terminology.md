# Meridian terminology

Rules in this file marked `must` are non-negotiable — the team called them out explicitly during setup.

## Use this

| Term | Casing | Context |
|---|---|---|
| trip | lowercase | The core object. Never "itinerary" (that's the day-by-day view inside a trip) |
| trip crew | lowercase | The people on a trip. Never "group," "party," or "members" |
| date poll | lowercase | The voting flow for picking dates |
| Meridian | capital M, never "the Meridian app" | Product name stands alone |
| organizer | lowercase | The person who created the trip. Never "owner" or "admin" |

## Never this

| Banned | Say instead | Why (enforcement) |
|---|---|---|
| "book" for anything Meridian doesn't transact | "reserve" or name the actual action | We don't process bookings; implying we do is a support and legal problem (**must**) |
| "guaranteed" about prices or availability | "usually holds," "as of today" | No price guarantees exist (**must**) |
| "cheap" / "cheapest" | "lowest fare we found" | Factual claim, not a value judgment (should) |
| "users" | "travelers" or "your crew" | Voice: we talk about people, not accounts (should) |
| "simple" / "easy" / "just" | describe the actual steps | If it were easy they wouldn't need the sentence (should) |
