# Example: Meridian

Meridian is a **fictional** group-travel planning app. This folder shows what a completed setup looks like — the output of one ~25-minute conversation, nothing more.

Notice what's *not* here: no 40-page style guide, no tone matrix, no glossary of 300 terms. Three small files, every rule approved by the (fictional) team, one rule marked `must` because they called it non-negotiable.

Do not copy these rules. They exist to show the shape, not to be your voice.
