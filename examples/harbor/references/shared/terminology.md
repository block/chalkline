# Reservation terminology

Scope: fictional Harbor reservation UI and support replies in English.

| Term | Use in this example |
|---|---|
| reservation request | A request whose confirmation has not been supplied as a fact |
| reservation | A reservation supplied as confirmed in the task facts |
| pickup location | The place supplied for collecting the equipment |
| equipment | The collective term; use the specific item name when supplied |

These distinctions guide wording; they do not establish a backend state model.
Ask for authoritative task facts if the state is unknown. Do not turn a person's
word “booking” into evidence of confirmation, and do not correct their phrasing
in a support reply merely to teach this table.
